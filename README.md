# geo411-precipitation
R analysis of precipitation data for Buffalo and San Diego

The following is some basic analysis of precipitation data from the cities of Buffalo and San Diego using data collected from 1940-2025. The goal of the analysis was to see if there were some years in which precipitation was late comparatively to other years. Additionally using the averages from the from the data gathered, probabilites were found whether preciptiation levels would reach above or below certain levels. 

Hypothesis testing

Key Findings (Buffalo: Mean, 38.82779, StDev, 5.43462. San Diego: Mean, 9.908605, StDev, 4.224307) 

T test results: Buffalo: p-value = 0.001188, indicates a significant difference at 95% confidence when trying to tell if precipitation will come early or late in Buffalo.

T test results: San Diego: p-value = 0.9552, indicates there is not enough evidence gathered to tell whether when trying to tell if precipitation will come early or late in San Diego 

Tools used: Assigned excel spreadsheet with precipitation data from 1940-2025 from San Diego and Buffalo, Rstudio.
